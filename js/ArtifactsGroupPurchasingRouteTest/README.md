# 联机团购路线测试

依次运行 AAA 狗粮联机团购内置的全部收尾路线和占位路线。每条路线结束后读取当前位置，计算其与路线文件最后一个点位的欧氏距离，并将结果写入 `路线运行情况.txt`。

BetterGI 路径执行器会在引擎内部处理路线异常，脚本无法直接取得路线内部的成功/失败状态。因此成功标准严格按路线结束后的终点距离判断：距离小于 10 记为成功，否则记为失败；坐标无法识别时距离为空，也会记为失败。路径接口调用异常会记录在备注中，单条路线异常不会阻断其他路线。

## 运行模式

- `完整运行`：清空上一轮状态并运行全部路线。
- `查漏补缺`：读取现有报告，只运行未运行或运行失败的路线。

报告会在每条路线完成后立即更新。任务中途停止时，下次可选择 `查漏补缺` 继续测试。

路线资源同步自 `ArtifactsGroupPurchasing/assets/ArtifactsPath`，包括 20 条前执行路线、8 条后执行路线和 7 条占位路线，不包含 `额外` 单人路线。
